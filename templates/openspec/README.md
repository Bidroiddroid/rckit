# OpenSpec

Use this directory to drive spec-first changes for this project.

- `config.yaml`: project context, conventions, rules, modules, and known pitfalls.
- `changes/`: active change proposals, designs, specs, and task lists.
- `specs/`: accepted baseline capability specs after changes are archived or synced.

Start a new change before implementing behavior, architecture, API, database, security, deployment, or integration work.
